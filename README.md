# Tollgate Timer

Вход на залипательные сайты платный, и платишь ты временем: динамический таймер входа на
сайты. Первые пара заходов — свободно, дальше каждый следующий вход дороже, вплоть
до потолка. Счётчик заходов тает сам по себе (без суточных сбросов), а круг таймера
заполняется только пока вкладка видима и в фокусе — «пересидеть в фоне» не выйдет.

## Как это работает

- **Заход** — это вход на сайт в конкретной вкладке. Свободны: навигация внутри
  вкладки, которая уже на сайте, и переход по ссылке с сайта в новую вкладку.
  Открытая где-то ещё вкладка сайта бесплатного входа НЕ даёт — иначе одна
  закреплённая вкладка навсегда отключала бы таймер.
- Ушёл и вернулся в пределах «окна сессии» (5 мин) — не новый заход, но окно не
  скользящее: спустя «возраст сессии» (20 мин от её начала) любой возврат — новый
  заход. Иначе чекинг каждые пару минут навсегда оставался бы «одной сессией».
- **Эффективный счётчик** = сумма весов заходов, каждый вес тает экспоненциально
  с периодом τ (6 ч по умолчанию). Утро начинается почти с нуля само.
- **Цена входа**: первые `freeVisits` заходов — без таймера, дальше
  `base × growth^n` секунд с потолком `cap`. Дефолт: 3-й заход — 15 с, 5-й — 44 с,
  7-й — ~2 мин, 10-й — 10 мин.
- Сайт при этом не грузится вообще: навигация перехватывается и уводится на
  страницу-шлюз, пока круг не заполнится.
- Кнопка «Передумал» закрывает вкладку мгновенно — правильное решение бесплатно.
  Заход засчитывается только при фактическом входе.

## Сборка

```bash
npm install
npm run build:firefox  # Firefox → .output/firefox-mv2
npm run zip:firefox    # пакет для AMO + архив исходников
```

Сборка под Chrome (`npm run build` / `npm run zip`) работает и поддерживается в коде,
но публикуется пока только Firefox-версия.

Режим разработки с автоперезагрузкой: `npm run dev` / `npm run dev:firefox`.
Тексты листинга, обоснования разрешений и порядок загрузки в сторы — в
[PUBLISHING.md](PUBLISHING.md); картинки для листинга — в `assets-store/`.

## Установка для тестирования

**Firefox**: `about:debugging#/runtime/this-firefox` → «Загрузить временное
дополнение» → выбрать `.output/firefox-mv2/manifest.json`. (Временное дополнение
живёт до перезапуска браузера; для постоянной установки нужен подписанный zip:
`npm run zip:firefox` → загрузить на addons.mozilla.org, хотя бы self-hosted.)

## Почему шлюз не появился

Попап показывает статус текущей вкладки и прямо отвечает на этот вопрос:
домен не в списке / ты внутри сессии в этой вкладке / идёт возврат в сессию /
бесплатные заходы ещё не кончились.

Шлюз ставится на **вход**, а не на навигацию: F5 и переходы внутри той же
вкладки свободны по замыслу.

Перехват работает в две ступени — до начала навигации и на её коммите. Вторая
ступень нужна из-за редиректов ДРУГИХ расширений: если что-то уводит
`youtube.com` → `youtube.com/feed/subscriptions`, шлюз всё равно сработает.

## Настройки

Попап расширения → «Настройки», либо страница параметров расширения.
Пресеты «Мягкий / Средний / Жёсткий» + ручная подкрутка всех параметров,
список сайтов, режим общего счётчика на все сайты.

Всё хранится в `storage.local`: `storage.sync` недоступен в части сборок на базе
Firefox и падает молча, из-за чего изменения списка сайтов могли не сохраняться.
Старые настройки из `sync` переносятся автоматически при первом запуске.

## Приватность

Расширение работает полностью офлайн: сетевых запросов нет, аналитики нет.
Список сайтов, параметры таймера и таймстемпы заходов лежат в `storage.local`
браузера и никуда не отправляются.
